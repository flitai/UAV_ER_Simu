# {{NAME}}：无人机电子侦察 IQ 数据说明

## 1 概述

本数据集是由仿真生成的无人机射频复基带 IQ 数据，共 {{N_SEGMENTS}} 段，每段 {{DURATION}} s。数据集的用途有两项：

1. 评估仿真数据在频谱、时频结构与统计特征上与真实无人机信号的相近程度；
2. 作为无人机信号检测、识别与参数估计算法的测试数据。

数据集按机型、信噪比、传播条件与信号组合四个维度系统取值，组成见第 4 章。文件格式与注记字段与「{{SAMPLE_NAME}}」相同，只有元数据中的两处有变化，见第 5 章第 6 条。

## 5 文件格式与物理量换算

1. 文件符合 SigMF {{SIGMF_VERSION}}。`core:datatype` 为 `ci16_le`，即 16 位小端复整数，I 与 Q 交织存放。
2. 码值换算为物理量的公式为：x = 码值 / 32768 × 10^(`cuav:full_scale_dBm` / 20)。x 的单位为 √mW，|x|² 的单位为 mW。同一接收配置下的全部文件使用同一满量程。
3. S3 为 ADC 输出的无损导出。S4 为数字下变频的输出，导出时经过一次重量化；当量化噪声低于接收机噪声底的余量不足 20 dB 时，导出工具把该文件的质量状态标为降级。每个文件的实际余量记在 `cuav:quality.export_requantization`，本数据集的实际值见第 10 章。
4. 数据采用逻辑仿真时间，从 0 s 开始，没有绝对时刻，因此元数据中没有 `core:datetime`，`cuav:time_basis` 为 `logical_sim`。
5. 本方定义的字段位于命名空间 `cuav:`，已在 `core:extensions` 中声明。
6. 与「{{SAMPLE_NAME}}」相比，元数据有两处变化：全局字段 `cuav:presets_version` 由字符串（如 `"v1"`）改为对象，按用到的机型参数表分别给出版本，如 `{"ofdm": "v2"}`；`core:extensions` 中 `cuav` 扩展的版本由 1.2.0 改为 1.3.0。其余全局字段与全部注记字段的名称、类型和含义不变。

### 6.1 发射功率的调整

以下两种情况调整发射功率，其余段均为标称 20 dBm：

1. 视距段按标称功率反解出的水平距离超过侦察站与平台之间无线电视距（按 4/3 等效地球半径计算）的 80% 时，平台放在该距离以内，差额由降低发射功率补足。不作调整时，地面遥控器在低信噪比档的距离会超出地平线。
2. 非视距段在无人机离地 40、30、20、10 m 处、按标称功率都找不到信噪比与目标相符的位置时，选择所需上调量最小的高度，把发射功率上调到恰好够，上调后不超过 30 dBm（等效全向辐射功率 32 dBm）。

## 8 信噪比的定义

注记同时给出两种信噪比。接收方可以用数据实测带内信噪比核对链路预算带内信噪比。

1. **链路预算带内信噪比**（`cuav:snr_dB`）按 P_rx − (kTF + 10·lg B) 计算。其中 P_rx 为发射功率加收发天线增益减路损，k 为玻尔兹曼常数，T 取 290 K，F 为接收机噪声系数，B 为该次发射的占用带宽。仿真开启小尺度衰落时，`cuav:snr_basis` 为 `link_budget_mean`，表示 `cuav:snr_dB` 是衰落的平均值；单次发射的实际信噪比随衰落起伏。
2. **数据实测带内信噪比**（`cuav:snr_measured_dB`）在本文件所属观测点的功率谱上测量。测量频段取注记的上下沿，两侧各加宽 2 个频点；信号功率取该次发射期间的谱行，噪声功率取同一频段上没有任何发射的谱行；信噪比按（信号功率 − 噪声功率）/ 噪声功率计算，再折算到占用带宽。以下情形不计算，字段为 null：与其他辐射源同时同频（依据字段为 `overlapped:<辐射源>`）、跨越可用频带边界（`capture_partial`）、位于可用频带之外（`capture_none`）。

## 9 可用频带与跳频遥控在 S4 中的覆盖

`cuav:usable_band_Hz` 的取值规则如下：S3 为 ±fs/2；S4 为数字下变频滤波器的通带，即 ±0.4 倍 S4 采样率；下变频不抽取时，取 S3 与 S4 两个频率窗口的交集。

含定频图传的段，S4 的中心频率与采样率使每个平台的定频图传全部落在 S4 的可用频带内；同一段中的其他信号（如 DroneID 广播、跳频遥控）不一定在 S4 内，以注记的 `cuav:capture` 为准。只含跳频遥控的段，S4 固定为 20 MS/s、中心频率 2440 MHz。因此跳频遥控只有一部分跳频点落在 S4 的可用频带内。各段的覆盖情况如下：

## 11 已知限制与适用范围

1. DJI 图传的 FFT 点数是假定（见第 6 章）。依赖 FFT 点数的分析不应以本数据为依据；循环前缀相关、子载波间隔估计可以使用。
2. 载荷为随机比特，没有信道编码，不含任何真实身份信息；DroneID 广播的载荷同样为随机比特。
3. 与公开实测数据的对照（见《无人机射频 IQ 信号仿真方法与可信性验证报告》）显示以下差异，本数据集未作修正：
   1. OFDM 符号之间没有加窗。信噪比高时，含符号交界的短时频谱比实测宽；
   2. DJI 遥控上行的跳频序列在频点表上随机取点，相邻两跳的频率差大于实测；
   3. 图传突发按固定时隙排布，突发间隔集中在时隙长度的整数倍上，实测的间隔分布更分散；
   4. GFSK 遥控的载荷为随机比特。实测 FrSky 遥控的频谱在一个频偏处有窄峰，本数据中没有；
   5. 小尺度衰落为平坦衰落，图传频谱的平坦度高于实测。
4. 接收为单天线、单通道，不含阵列数据，不适用于测向算法的评估。
5. 地面按平地处理，地面高度为 0 m，不含地形遮挡。
6. 建筑绕射只计入侵入最深的一栋建筑，按单刀口计算；不计多次绕射与反射。
7. 衰落参数（K 因子）与载频偏差的范围是假定值，不是实测拟合值。
8. 部分段的发射功率不是标称值（见第 6.1 节）；非视距段无人机的高度随信噪比目标变化。
9. S4 在导出时经过一次重量化；需要无损数据时使用 S3。
10. Futaba S-FHSS 按开源协议实现生成。公开数据集中的 Futaba 实测数据采用的不是 S-FHSS 协议，二者不能直接比较。
11. 5.8 GHz 的 20 MHz 档图传没有实测依据（见第 6 章）。
12. 纯背景段的场景中有一个全程关断的占位辐射源。链路文件中有它的几何记录，注记中没有它。
13. 本数据为原型阶段的仿真合成数据，未经目标接收机实测校准。

## 12 读取方法

Python（需要 numpy；`--png` 输出一幅时频图）：

```
python examples/read_sigmf.py data/{{EXAMPLE_STEM}}_s3 --png {{EXAMPLE_PNG}}
```

MATLAB（先把 `examples/read_sigmf.m` 加入 MATLAB 路径）：

```
[x, meta] = read_sigmf('data/{{EXAMPLE_STEM}}_s3');
```

也可以使用 SigMF 官方 Python 包（`pip install sigmf`）读取。
