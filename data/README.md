# data 目录

数据产物。**大文件不入 git**，只有说明文件（`*.md`）与清单文件（`*.manifest.json`）入库。
忽略规则见根目录 `.gitignore`。

| 子目录 | 内容 |
|---|---|
| `iq/measured/` | 实测 IQ |
| `iq/synthetic/` | 合成 IQ |
| `iq/mixed/` | 混合增强：实测背景加合成目标 |
| `scene/<aoi>/` | 场景数据包，规范见 `docs/scene-package.md` |
| `golden/` | 黄金基准 |

## 三条纪律

1. **每个数据产物挂同构元数据**：来源、参数、输入哈希，以及溯源八件套（铁律 8）。
2. **验收子集入库即冻结**：按设备、日期、地点、架次划分，记录文件哈希。事后再补等于
   已经泄漏。
3. **合成数据不用于展示**（铁律 14）：演示与交付图一律用真实数据，或显式标注。估算标记
   （例如建筑高度的 `est:*`）与合成底噪标记必须随字段传到每一个下游产物。
