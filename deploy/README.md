# deploy 目录

部署包：单机一体化包、内网集中部署包、离线静态资源、启动器。对应 04 号方案的 WP8。

## 已冻结

| 项 | 内容 | 依据 |
|---|---|---|
| 运行形态 | 浏览器加服务端。单机模式由本地启动器拉起应用服务并打开系统浏览器 | 04 §2.5、§6.5 |
| **不用 Tauri** | 其自定义协议不支持 Range，且 WKWebView 明显慢于 Chrome | 决策 D-003 |
| 客户端与单机包 | Windows x64 优先 | 决策 D-015 |
| 集中部署服务端 | Windows 或 Linux x64 视情况选择 | 决策 D-016 |

## 尚未决定

单机启动器的形态：批处理文件加便携版 Node、单文件可执行程序，或 Windows 服务。决策时点是
阶段 2 设计报告。

## Windows 打包的已知坑

1. 启动脚本 `.bat` 必须用 GBK 编码加回车换行的换行符，否则中文乱码或无法执行
2. 在 macOS 上用 zip 打包，中文文件名到 Windows 解压会乱码。因此出包前必须跑
   `scripts/check-ascii.sh`（铁律 15）
3. Windows 的原生构建无法在 macOS 上交叉完成，需要 Windows 机器或持续集成
