一、运行环境
  · Windows 10 或 Windows 11，64 位。
  · 不需要联网，不需要另装任何软件。程序窗口自带浏览器内核。
  · 备用启动方式（start.bat）要用系统浏览器：Microsoft Edge（系统自带）或其他
    Chromium 内核浏览器，必须支持 WebGL2。

二、安装
  1. 把压缩包解压到一个可写的目录，例如 D:\cuav\。
     不要解压到 C:\Program Files 下面：系统运行时要在 data 目录里写任务结果。
  2. 解压后的目录里有 app 目录（程序本体）和 start.bat（备用启动方式）。
     可以在 app\CuavDemo.exe 上点右键，选「发送到 → 桌面快捷方式」。

三、启动与停止
  启动：双击 app\CuavDemo.exe。程序先显示「正在启动服务」，几秒后进入系统界面。
  停止：关闭程序窗口。运行中的任务会先正常结束，再退出。
  首次运行时，Windows 防火墙可能询问是否允许访问网络：服务只在本机
  127.0.0.1 上监听，选「取消」也不影响使用。
  界面在窗口宽度不足 1920 像素时收起左右两栏，程序按屏幕宽度自动缩小页面；
  可以用菜单「视图」里的放大 / 缩小 / 实际大小调整（按 Alt 键显示菜单栏）。

  备用启动方式：双击 start.bat。屏幕上出现一个命令行窗口；服务就绪后，系统用
        默认浏览器打开 http://127.0.0.1:8080/ 。关闭这个命令行窗口即停止服务。
  如果服务已在运行（例如已经用 start.bat 启动），再打开 CuavDemo.exe 时直接使用
  这一份服务，不启动第二份；此时关闭程序窗口不会停止服务。

四、端口被占用
  如果提示端口 8080 已被其他程序占用：关闭占用该端口的程序后重新打开；或者改用
  start.bat：用记事本打开 start.bat，把 "set PORT=8080" 中的 8080 改成其他端口
  （例如 8081），保存后再双击 start.bat。

五、数据位置
  data\runs\      每次运行的结果。
  data\exports\   在「结果 → 数据导出」页签导出的 SigMF 文件。
  data\diagrams\  保存的框图。
  data\tmp\server.log  程序窗口启动的服务的运行日志。
  服务与引擎只在本目录内写文件，不写注册表。程序窗口的界面设置（如浅色 / 深色）
  保存在 %APPDATA%\CuavDemo。卸载时删除整个目录即可。

六、包内容
  package.manifest.json 列出包内每个文件的大小与 SHA-256。
  第三方软件与数据的许可见 THIRD-PARTY-NOTICES。
