一、运行环境
  · Windows 10 或 Windows 11，64 位。
  · 浏览器：Microsoft Edge（系统自带）或其他 Chromium 内核浏览器，必须支持 WebGL2。
  · 不需要联网，不需要另装任何软件。

二、安装
  1. 把压缩包解压到一个可写的目录，例如 D:\cuav\。
     不要解压到 C:\Program Files 下面：系统运行时要在 data 目录里写任务结果。
  2. 解压后的目录里有 start.bat。

三、启动与停止
  启动：双击 start.bat。屏幕上出现一个命令行窗口；服务就绪后，系统用默认浏览器
        打开 http://127.0.0.1:8080/ 。
  停止：关闭这个命令行窗口。
  如果浏览器没有自动打开，在浏览器地址栏输入上面的地址。
  如果服务已在运行时再次双击 start.bat，系统只打开浏览器，不启动第二份服务。

四、端口被占用
  如果命令行窗口提示端口 8080 已被其他程序占用：用记事本打开 start.bat，
  把 "set PORT=8080" 中的 8080 改成其他端口（例如 8081），保存后再双击 start.bat。

五、数据位置
  data\runs\      每次运行的结果。
  data\exports\   在「结果 → 数据导出」页签导出的 SigMF 文件。
  data\diagrams\  保存的框图。
  服务与引擎只在本目录内写文件，不写注册表。卸载时删除整个目录即可。

六、包内容
  package.manifest.json 列出包内每个文件的大小与 SHA-256。
  第三方软件与数据的许可见 THIRD-PARTY-NOTICES。
