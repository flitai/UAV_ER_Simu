一、运行环境
  · Windows 10 或 Windows 11，64 位。
  · 不需要联网，不需要另装任何软件。程序自带浏览器内核与运行环境。
  · 用户目录所在的磁盘（通常是 C 盘）要有约 0.5 GB 空闲空间，见第三节。

二、安装
  1. 把压缩包解压到任意目录，例如 D:\cuav\。解压出的目录就是程序本身。
  2. 可以在 CuavDemo.exe 上点右键，选「发送到 → 桌面快捷方式」。

三、首次运行
  双击 CuavDemo.exe。第一次运行时，程序把自带的运行环境（服务、地图、建筑与
  实测数据，约 0.4 GB）拷到下面的目录，需要几十秒，之后再打开就不用等：
      %LOCALAPPDATA%\CuavDemo\runtime\{version}
  任务结果与导出的文件都写在这个目录里，所以程序本身可以放在只读的位置。
  首次运行时，Windows 防火墙可能询问是否允许访问网络：服务只在本机 127.0.0.1
  上监听，选「取消」也不影响使用。

四、启动与停止
  启动：双击 CuavDemo.exe。程序先显示「正在启动服务」，几秒后进入系统界面。
  停止：关闭程序窗口。运行中的任务会先正常结束，再退出。
  界面在窗口宽度不足 1920 像素时收起左右两栏，程序按屏幕宽度自动缩小页面；
  可以用菜单「视图」里的放大 / 缩小 / 实际大小调整（按 Alt 键显示菜单栏）。

五、端口
  程序使用本机端口 8080。8080 被其他程序占用时，程序自动改用 8081～8099 中
  第一个空闲的端口，不需要设置。

六、数据位置
  菜单「文件 → 打开数据目录」打开下面这些目录所在的位置：
  data\runs\      每次运行的结果。
  data\exports\   在「结果 → 数据导出」页签导出的 SigMF 文件。
  data\diagrams\  保存的框图。
  data\tmp\server.log  服务的运行日志。
  程序不写注册表。卸载时删除程序目录，并删除 %LOCALAPPDATA%\CuavDemo 目录
  （其中有任务结果，删除前先确认不再需要）。界面设置（如浅色 / 深色）保存在
  %APPDATA%\CuavDemo。

七、包内容
  package.manifest.json 列出包内每个文件的大小与 SHA-256。
  第三方软件与数据的许可见 resources\payload\THIRD-PARTY-NOTICES。
