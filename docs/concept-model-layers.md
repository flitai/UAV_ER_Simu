# 概念模型的层次归属

**状态**：骨架。族级归属已由决策 D-011 冻结（内容与 `CLAUDE.md` 同步），60 份逐份确认待做。

**依据**：01 号方案 §3.5 的判据与 §9.2；02 号方案 §6.1；决策 D-011、D-012。

---

## 1. 为什么需要这份文件

`C-UAV Model Demo/概念模型/` 下的 60 份概念模型文档，表头里**没有 M 层字段**。而 01 号方案
要求每个模型同时声明三个正交维度（模型层次 M、精度档 E、可信度 V）。本文件按 01 §3.5 的
判据补上 M 层归属。

本系统建设的是 M2 信号级加 M3 IQ 级。概念模型库在本系统中只有两种角色：**向下的参数供给层**
与**向上的归约目标层**。IQ 级不是另一套模型，而是同一条电侦模型链的高粒度展开。

## 2. 族级归属（已冻结）

| 族 | M 层 | 在本系统中的角色 |
|---|---|---|
| EM-B-07 天线 / B-11 接收机基础 / B-12 噪声 | M1 参数供给 | 复增益与极化损耗；接收采样链的能力边界（噪声系数、带宽、增益、自动增益控制、阻塞）；样本级噪声的目标功率谱密度 |
| EM-B-09 信号抽象 / EM-T-03 辐射源特性 | M1（E1、E2 档），E3 档的时频包络进 M2 | 波形模板与业务活动的输入：频率计划、带宽、功率、谱形、突发与跳频摘要、调制家族。保持「不生成 IQ」的边界 |
| EM-B-10 频谱栅格 | M2 | M3 归约后时频观测产品的容器；也为 IQ 任务选择频段、时间窗口与背景源 |
| EM-P-01 / 02 / 04 / 08 / 13（P-03 / 05 / 07 备用） | M1、M2 | 路径损耗、双径、建筑遮挡、阴影、模型选择与降级，产出慢变信道参数。P-11 射线追踪与 P-12 缓存归入后置能力包 P3 的多径路径端口 |
| EM-S-01 扫描策略 | M2 调度 | IQ 捕获窗口：时间窗、中心频率、驻留时间、采样上下文 |
| EM-S-02 / 03 / 04 检测、特征、识别 | M2 裁决 | 只消费 M3 归约出的观测量，不碰原始 IQ。其检测概率曲线与特征模板是 M3 蒙特卡洛的校准对象 |
| EM-S-05 / 06 / 07 / 08 测向定位 | M2 | 首期只作为 M3 观测量（到达时间、方位）的接口与误差语义参考，实现放在后置能力包 P1、P2 |
| EM-S-10 / 11 / 12 运动估计、关联、退化 | M1、M2 | 退化模型提供 IQ 质量标记的映射：削顶、镜像、缺样对应到检测与识别的质量修正 |
| EM-T-04 建筑材质 | M2 参数 | 首期不用（铁律 12），后置能力包 P3 启用 |
| EM-R / J / H / N / C / F 六族，以及 EM-T-01 / 02（雷达目标散射截面、微多普勒） | M1 效应裁决 / 雷达目标特性 | **在 04 号方案的电侦范围之外，本系统不使用**。保留引用；如需纳入，必须先修订 04 |
