## 1. 一条贯穿始终的原则

**画布不自行解释任何规则。** 组件有哪些、参数是什么类型与单位、取值范围多少、
哪两个端口能连、连不上的理由是什么，全部来自引擎生成的组件目录
（`GET /api/v1/components`，由 `cuav_run --catalog` 导出）。

对使用者的实际意义是：**画布里能画出来的，引擎就一定认；画布拒绝的，引擎也一定拒绝。**
两者不会给出互相矛盾的结论，也不存在「界面允许但提交后报错」的情形。
唯一的例外是需要跨节点或跨文件才能判断的检查（场景哈希、时长关系等），
那些由提交时的 `cuav_run --validate` 完成，见第 4 节。

## 2. 基本操作

### 2.1 建立框图

| 操作 | 做法 |
|---|---|
| 载入示例 | 工具条「示例框图」下拉，现有三种：单音加噪声到功率谱（合成链）、场景绑定链路到功率谱（demo-01 亚运村）、实测片段回放到功率谱 |
| 添加节点 | 左栏组件库里**点一下**该组件，或把它**拖到画布上**。拖放会落在指针位置，点击则依次排开 |
| 选中节点 | 单击节点。右栏随即显示它的参数面板 |
| 移动节点 | 拖动。位置按 16 px 网格吸附 |
| 复制节点 | 选中后 `Ctrl+Shift+D`。参数一并复制，标识自动追加序号 |
| 删除节点 | 选中后 `Delete` 或 `Backspace`。与它相连的连线、挂在它上面的观测点会一并删除 |
| 画布平移缩放 | 空白处拖动平移；滚轮缩放；左下角有缩放与「适应视图」按钮 |

节点的标识（`id`）由类型名派生并自动去重（`tone`、`tone-2`）。在参数面板改标识时，
引用它的连线与观测点会自动跟着改，不会留下悬空引用。

### 2.2 连线

从一个输出口（节点右侧）拖到另一个节点的输入口（左侧）。

- **把手形状表示端口类型**，不只靠颜色：实心圆 = `IQStream`，实心菱形 = `SceneParamFrame`，
  实心方 = `SpectrumFrame`，实心三角 = `DetectionList`，
  六边形 = 报告族（`BearingReport` / `ToaReport` / `PositionReport`，D-053）。悬停可看端口名与类型。
- **参数流的连线画成虚线**，与 IQ 主干在视觉上分开。
- 连线不合法时会被拒绝，画布底部给出**目录原文的理由**，并补一句可操作的建议。
- **删除连线**：单击该连线。

### 2.3 参数面板

右栏的每一项都由目录生成，包括控件类型、单位、取值范围。

- **数值框接受工程计数法**：`2.44G`、`500k`、`20M`、`1e6`、`6.1u` 都可以，底层一律存 SI 基本单位。
  输入不合法时输入框标红，不会猜。
- **清空一个数值框即回到缺省值**，此时显示为浅色，且该键不会写进框图文件。
- **互斥参数并排显示、共用一个单选**（例如噪声源的 `power` 与 `power_dBm`）。
  只能填其中一个，选中另一个时前一个自动清空。
- **必填且没有缺省值的参数**会在面板上方标「待填」，节点显示未校验态。
- 参数名过长时鼠标悬停可看全名与说明。

### 2.4 观测点

观测点是挂在 `IQStream` 输出口上的抽头，不是节点。

| 操作 | 做法 |
|---|---|
| 打观测点 | 在节点上**右键**。会挂在该节点的第一个 IQ 输出口上 |
| 打开已有观测点 | 单击节点下方的 `◉ <标识>` 标记 |
| 改标识、显示名、产品、参数 | 在观测点面板里改 |
| 删除观测点 | 选中后 `Delete` |

产品有「频谱」「包络」两项可选，**「IQ」置灰**，原因见第 5 节。

### 2.5 场景绑定

目录里标了可绑定场景的组件（`ScenarioSource`、`SceneEmitterSource`、`SceneBoundChannel`）
在参数面板顶部有「场景绑定」区，两个下拉：先选场景，再选站点或实体。

- **`ScenarioSource` 的输出口是动态的**：绑定场景之前它没有输出口；绑定之后按该场景的辐射源
  生成 `link:<辐射源标识>` 端口。
- **改绑定会删掉端口已不存在的连线**，并提示删了几条。
- 实体下拉只在该场景**已经载入**时有内容（见第 5 节）。

### 2.6 运行

工具条「运行」按钮或 `Ctrl+Enter`。提交前服务端会同步跑一次引擎的 `--validate`：
通过则建任务并开始跑，不通过则不建任务，错误列在画布下方。

**错误定位**：每条错误带错误码、节点标识与端口。**单击一条错误即跳到并选中对应节点**；
出错的节点边框变警示色，出错的端口把手加警示环。
任何一次编辑都会清空**全部**错误标记与校验结果，因为旧报文已不再描述当前的框图；
要重新得到结论，再跑一次校验。

### 2.7 撤销与重做

工具条的 ↶ ↷ 两个按钮，栈深 50。一次拖动只记一步，不是每帧一步。

> `Ctrl+Z` / `Ctrl+Y` **尚未接到框图上**（09 §11 有约定，实现待补），当前只能用工具条按钮。

### 2.8 回到典型链路

画布工具条最左边的「← 回到典型链路」与典型链路那边的「展开为自由画布」对称，两个方向都通。
顶栏「框图」页签与 `Alt+2` 也回典型链路（它们回的是框图页的默认形态）。

按下时先看当前框图还解不解得回九个槽位：

| 情形 | 行为 |
|---|---|
| 只改过参数、勾过观测点、挪过节点位置 | 直接回，不问 |
| 加过模板之外的节点（连线、观测点跟着变也算） | 当场给一条黄色说明并要确认：**当前框图已不是典型链路的形状，回去只能新建一条链**。选「留在画布」什么都不变；选「仍要回去」也**不会丢改动**——落在典型链路页的「不是本模板」提示上，那里再点「新建典型链路」才真的换掉文档，或者点「在自由画布打开」原样回来 |

**删**节点不影响解回：缺席的环节按旁路或缺省处理。只有**加**了模板之外的节点才解不回。

## 3. 快捷键

| 键 | 作用 |
|---|---|
| `Alt+1 / 2 / 3 / 4` | 切到场景 / 框图 / 结果 / 数据中心。在画布里按 `Alt+2` 会回到典型链路视图（§2.8） |
| `Ctrl+Enter` | 校验并运行 |
| `Delete` / `Backspace` | 删除选中的节点或观测点 |
| `Ctrl+Shift+D` | 复制选中节点 |
| `Ctrl+S` | 标记为已保存（**只在本页**，见第 5 节） |
| `` Ctrl+` `` | 收起 / 展开底部抽屉 |

输入框获得焦点时，上述画布快捷键不生效。
`Ctrl+D` 不绑定，它是浏览器的「收藏此标签页」。

## 4. 约束：画布当场拒绝的

这些在画布上就构造不出来，不必等到提交。

| 约束 | 说明 |
|---|---|
| **端口类型必须相同** | 六种端口类型两两之间只有同类型可连。兼容矩阵是 6×6 全枚举共 36 条，全部来自目录 |
| **IQ 流与参数流不得直连** | `IQStream` 与 `SceneParamFrame` / `ChannelPathSet` 之间必须有一个施加类组件（决策 D-013）。理由是「参数如何作用于样点」必须由具体模型显式承担，不能由一条连线隐含表达 |
| **一个输入口只能连一条边** | 需要合并两路信号时用加法混合这类多输入组件 |
| **观测点只能挂在 IQ 输出口上** | 挂到别的类型上会被拒绝 |
| **互斥参数只能填一个** | 由单选控件保证，因此「互斥冲突」这个错误在画布路径上不可能发生 |
| **内部参数不出现** | 文件路径一类的参数由服务端注入，画布不显示也不写进框图文件（决策 D-037） |

## 5. 限制：当前实现做不到的

以下不是缺陷，是首期的边界或尚未排期的功能。**使用前需要知道**。

### 5.1 框图不落盘

**框图只存在于浏览器当前页面。** `Ctrl+S` 与「保存」只是把当前内容标记为已保存，
服务端没有框图的存取端点，刷新页面即丢失。要保留一份，用开发者模式的「源码」页签
（地址加 `?dev=1`）把 JSON 复制出来。任务一旦提交，那一份框图会随任务留在
`data/runs/<任务号>/diagram.json`，可以从那里取回。

### 5.2 天线与接收机两类没有组件

组件库里这两个分组显示「本期无组件」。04 §8.1 规定的是六类，所以分组保留、不隐藏，
但首期确实一个都没有。天线与接收机的效应目前折在信道与源里。

### 5.3 观测点的「IQ」产品不可选

引擎本版本不产出原始 IQ 产品，对含 `iq` 的框图会明确报错而不是静默忽略（决策 D-040 ③），
所以画布把这个开关置灰。结果页的 IQ 散点也因此没有数据源。落盘格式定稿后放开。

### 5.4 场景实体下拉依赖场景已载入

场景**列表**总是可选，但**实体与站点的标识**只有该场景已经载入时才有。
首期只有一个演示场景且开页面时会自动载入，通常感觉不到；将来多场景时，
未载入的场景在绑定区会提示「先到场景视图打开它」。

### 5.5 回放源不能绑定场景

实测数据片段与地理场景无关，目录里它就标了不可绑定，运行期引擎还会再拒一次。
这是有意的两道防线。

### 5.6 没有子系统封装、模板与旁路

把若干节点折叠成子系统、存为模板、临时旁路某个节点做 A/B 对比，这些属于 04 §8.2 的
P2 阶段能力，需要框图文件格式增加字段，本期不做。

### 5.7 尚未实现的交互（设计已定）

09 §6 定了但当前实现还没有的，列在这里以免误以为是缺陷：

- **`Ctrl+Z` / `Ctrl+Y`** 尚未接到框图（只能用工具条按钮）
- **双击画布空白弹出组件搜索框**（键盘路径），未实现
- **拖动时的对齐参考线**，未实现；网格吸附已有
- **右键菜单**：当前右键直接在第一个 IQ 输出口上打观测点，没有弹出菜单，
  因此无法选择挂在哪个输出口（多 IQ 输出口的组件目前只有这一种落点）
- **框图与场景视图的反向高亮**（选中绑定节点后在场景里高亮对应对象），未实现

## 6. 出问题时怎么查

| 现象 | 先看哪里 |
|---|---|
| 组件库空着，写「组件库不可用」 | 引擎二进制没构建或服务端起不来。服务端日志会写引擎路径 |
| 运行按钮点不动 | 已有任务在跑；或框图 JSON 解析不了（错误列表第一条会是 `json_parse`） |
| 提交后报错但画布上没高亮 | 该错误没有节点定位（如顶层结构错误），看错误列表的文字 |
| 节点一直是未校验态 | 还没跑过校验；点「运行」或 `Ctrl+Enter` 后才会变 ✓ 或 ✕ |
| 想看框图的原始 JSON | 地址加 `?dev=1`，工具条出现「画布 / 源码」两个页签 |

**开发者模式**（`?dev=1`）另外会显示：参数面板底部的溯源（模型编号、M/E 档、版本、实现来源）、
源码页签。正常使用时这些不显示，界面上不解释数据来源（决策 D-039、D-042b）。
