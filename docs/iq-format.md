## 1. 适用范围与主产品定义（已冻结）

本系统的主产品是 **S4 观测点的 IQ 数据**，即数字下变频（DDC）之后、信道化之前的宽带
复基带 IQ。本规范约束该产品的存储、交换与元数据。

专业模型组不得自行改变 IQ 的语义。任何"看起来更方便"的语义变更（例如把信道化之后的
子带数据也叫作 S4）都属于违规。

## 2. 采样与频率约束（已冻结）

| 约束 | 内容 | 依据 |
|---|---|---|
| 频率占用 | 频偏绝对值加二分之一带宽再加保护带，必须小于二分之一采样率 | 铁律 4 |
| 抽取 | 抽取之前必须先做抗混叠滤波 | 铁律 4 |
| 常用采样率 | 5 至 50 兆样点每秒 | 04 §12.1 |
| 高采样率 | 100 兆样点每秒仅用于文件兼容与短时间窗，不作为主用工作点 | 04 §12.1 |

**已冻结**：交换与保存使用复数 16 位整数交织排列；程序内部计算使用 32 位浮点。

## 4. 元数据（骨架，字段待写）

**已冻结的原则**：元数据与 SigMF 规范兼容；每个数据产物挂同构元数据，记录来源、参数与
输入哈希；溯源字段为六件套加两项扩展，共八项。

| 字段 | 含义 | 依据 |
|---|---|---|
| `model_id` | 模型标识 | emcore 六件套 |
| `model_version` | 模型版本 | 同上 |
| `model_level` | 精度档 E1 至 E4 | 同上，01 号方案 |
| `model_layer` | 模型层次 M1 / M2 / M3 | D-012 |
| `credibility` | 可信度 V1 至 V5 | D-012 |
| `parameter_version` | 参数版本 | emcore 六件套 |
| `confidence` | 置信度 | 同上 |
| `trace_id` | 溯源标识 | 同上 |

**待写**：采集类元数据的完整字段表（采样率、中心频率、设备型号、天线、增益、时间基准、
连续性标志、坐标与坐标版本），以及每个字段的必填性、取值域与来源标注方式。

**必须记录来源标注**：参数是设备实测记录，还是来自文档转述。理由见第 8 节的反面教材。

## 5. 功率与标定口径（待写，被数据阻塞）

需要回答的问题：量化码如何换算为分贝毫瓦；需要哪些标定量（天线增益、馈线损耗、接收机
增益设置、标定常数）；未标定数据如何标记，以及未标定数据允许参与哪些验证、禁止参与
哪些验证。

本节在甲方实测数据与八项摸底问题得到回答之前无法定稿。

## 6. 时间基准（已冻结）

逻辑仿真时间、文件采集时间、设备硬件时间、外部统一时间这四重时间不得混用。元数据必须
填写所用的时间基准与连续性标志。失锁、补零、重新对齐之后的数据不得当作连续数据。

## 7. 结果状态四态（已冻结）

`valid`、`degraded`、`invalid`、`not_applicable`。禁止用默认值顶替缺失值。

## 8. 已知的真实样本

目前唯一在手的真实 IQ 数据集是公开数据集 DroneRFb-DIR。它与本规范的关系有两点：

1. 它的数据本身正好落在 S4 观测点，可作为本规范的第一个真实样本。
2. 它是「元数据必须外挂」这条要求的反面教材：其文件内部没有任何元数据，采样率、中心
   频率、设备型号只写在随附论文里，一旦数据与论文分离就无法解释。

摸底的完整结论见 `WORKLOG.md` 的 2026-09-03 条目。
