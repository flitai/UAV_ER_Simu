# 决策记录

## 与 CLAUDE.md 决策日志的分工

`CLAUDE.md` 的决策日志是**索引**：每条决策一行，记编号、日期、结论、依据与影响。

本目录存放**需要展开论证的决策**的完整记录。不是每条决策都需要在这里建文件——只有当
「一行写不下论证过程」或者「否决的方案值得记下来供以后复查」时才建。

## 文件命名

`D-0xx-<英文短标识>.md`，例如 `D-018-dataset-dronerfb.md`。文件名必须是纯 ASCII。

## 记录格式

```markdown
# D-0xx <一句话结论>

- 日期：
- 状态：已定 / 暂定（PROVISIONAL）/ 已废止（被 D-0yy 取代）
- 依据：

## 问题

## 候选方案

| 方案 | 优点 | 缺点 | 结论 |

## 结论与理由

## 影响到哪些地方

## 复查条件
（在什么情况下需要重新审视这条决策）
```
