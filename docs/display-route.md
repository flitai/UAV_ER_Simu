## 4. 色值重新标定（2026-09-06 完成，切片 ② 的 D2-4）

底图上会与态势元素相邻的三种背景取自 `web/src/scene/style/colors.ts` 的 `PM` 表：

最低的一项是视距绿对水面 3.56:1，仍高于 3:1 门槛。**视距绿 / 非视距红这对语义沿用 em-demo**
（第 3 节已冻结），只是把色相压深、饱和度降下来适应浅色底。

**测向线与误差椭圆自 D-053（2026-09-09）起有生产者**：`DirectionFinder` 出 `bearings.jsonl`、
`MultiSiteLocator` 出 `positions.jsonl`，画在 `web/src/scene/layers/fixOverlay.ts` 的 Canvas 叠加层上
（第 3 节冻结的语义就是它）。画法：测向线从站址沿量测方位画，有定位解时画到解算点再延伸 20%、
没有则画固定 3 km；`±2σ` 楔形低透明度填充，裁决非 `valid` 画虚线，`use_policy = exclude` 不画；
定位点画十字加 2σ 椭圆（12% 填充），三种方法三个色；标签只在 `?dev=1`（D-039，界面不主动解释）。
上面三行色值按 D2-4 的同一判据实测，最低 3.57:1 过 3:1 门槛；em-demo 的橙 `#f97316` 与青 `#22d3ee`

**仍然没有的**：威胁分级红黄绿、效应染色、覆盖场 viridis、等检测概率包络——

## 5. 遮挡计算（已定方案，落点待定）

从 `C-UAV Model Demo/emcore/` 移植到本项目 `geo/` 目录的三部分：

1. `IMapQuery` 接口，含地形高度查询、建筑查询、射线求交、材质查询
2. `LocalSceneAdapter`，100 米桶网格加数字微分分析线段遍历，命中语义是「侵入最深的等效单刀口」
3. `models/occlusion`，ITU-R P.526 刀口衍射

遮挡是软的，不是二值遮挡：雷达用信干噪比减去二倍衍射损耗，单程链路用接收功率减去衍射
损耗；实时计算与覆盖场使用同一个注入点。

移植后必须通过两项验证才算可信：148 例黄金基准对拍，相对误差不超过 1e-9；以及独立的
解析锚点，例如 2.4 吉赫兹、1 千米处的自由空间路径损耗约等于 100.1 分贝。

**待写**：遮挡计算放在服务端预计算并经 WebSocket 推送，还是放在浏览器用 TypeScript 复算
并与 C++ 黄金基准对拍。此项属未决事项，决策时点是 D3 设计报告。

### 6.2 与 Airports 的并排比对结果

同一底图文件、同一相机（中心 116.405, 39.99，缩放 14.2，俯仰 55 度）、同一 1200 × 713 视口，
两边都只留底图（关掉三维建筑、山体阴影，隐藏侧栏与控件），逐像素比较：

| 指标 | 结果 |
|---|---|
| 容差 8 以内的像素 | 99.83% |
| 逐位完全相同的像素 | 93.72% |
| 平均绝对差 | 0.15（满量程 255） |

**不是逐位相同，也不应该是**：本项目用 MapLibre GL 5.24.0，Airports 用 5.6.1（决策 D-008
有意锁定同 em-demo 的版本），两版在文字排布与抗锯齿上有亚像素差别；另外参照页还多 5 个它
自己的机场要素图层。判据取"看起来是不是同一张图"，99.83% 是通过。
