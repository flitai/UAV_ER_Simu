## 3. 从 em-demo 沿用的图形语义（已冻结）

- 威胁等级用红、黄、绿三色；效应染色的优先级高于威胁等级
- 测向线与到达时间差定位用两种颜色区分
- 覆盖热力图用 viridis 色带分五档，叠加按数值变化的不透明度
- 等检测概率包络线用移动方块算法生成，画在建筑之上
- 平面位置显示扫描、测向线、二倍标准差误差椭圆走 Canvas 叠加层，用地图的投影函数换算像素坐标
- 状态更新用固定频率的定时器（20 赫兹），每帧提交一次状态
- 无人机图标用 SVG 光栅化后以 `source-in` 方式染色，用 `icon-rotate` 表示航向
- 航迹做抽稀

参考文件：`em-demo/src/components/{MapView,CoverageControl,SignalPanel}.tsx`、
`em-demo/src/models/coverage.ts`、`em-demo/src/simulation/engine.ts`。

## 5. 遮挡计算（已定方案，落点待定）

从 `C-UAV Model Demo/emcore/` 移植到本项目 `geo/` 目录的三部分：

1. `IMapQuery` 接口，含地形高度查询、建筑查询、射线求交、材质查询
2. `LocalSceneAdapter`，100 米桶网格加数字微分分析线段遍历，命中语义是「侵入最深的等效单刀口」
3. `models/occlusion`，ITU-R P.526 刀口衍射

遮挡是软的，不是二值遮挡：雷达用信干噪比减去二倍衍射损耗，单程链路用接收功率减去衍射
损耗；实时计算与覆盖场使用同一个注入点。

移植后必须通过两项验证才算可信：148 例黄金基准对拍，相对误差不超过 1e-9；以及独立的
解析锚点，例如 2.4 吉赫兹、1 千米处的自由空间路径损耗约等于 100.1 分贝。

**待写**：遮挡计算放在服务端预计算并经 WebSocket 推送，还是放在浏览器用 TypeScript 复算
并与 C++ 黄金基准对拍。此项属未决事项，决策时点是 D3 设计报告。
