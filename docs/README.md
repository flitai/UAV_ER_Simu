# docs 目录说明

本目录存放**被代码引用的规范**。与根目录的方案文档分工如下：

| 文件位置 | 定什么 | 谁改 |
|---|---|---|
| 根目录 `01`–`05` 号方案 | 做什么、为什么这样做。只读，不修改 | 上游 |
| 根目录 `CLAUDE.md` | 约定、状态与决策。冲突时以它为准 | 每次会话 |
| 根目录 `06` 号备忘录 | 顺序与步骤 | 每完成一步 |
| 根目录 `WORKLOG.md` | 过程与量化结果 | 每个任务节点 |
| **本目录** | 代码实现时必须遵守的具体规范（字段名、字节序、端点、文件布局） | 实现该部分时 |

## 写作要求

用完整句子。不使用未在本文件内定义过的内部简称。每条结论标明依据（例如「04 §5.2」或
「实测，见 WORKLOG 2026-09-03」），并区分「已冻结」与「待写」。
