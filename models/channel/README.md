# 模型卡：传播效应的组合与逐项模型

**库**：`geo/include/cuav_geo/propagation.h` + `geo/src/propagation.cpp`（零第三方依赖，只用标准库）。
**入口**：`geo::link_budget()`；配置来自组件 `ScenarioSource` 的十五个参数，界面上显示在「传播信道」卡片右栏。
**分级**：M2 参数供给 / E1–E2 / V1–V2（逐项见 §3）。**依据**：01 §3（精度等级 E1–E4）；04 §7.3（传播模型
简化策略）、§12.2（慢变参数在采样率上施加）；05 §5.2、§6.2.3；概念模型 EM-P-01 / P-02 / P-05 / P-07 / P-08 /
P-13；12 号报告；决策 D-009、D-013、D-019、D-028、D-049、D-058。
**落地**：2026-09-10，R-1 至 R-7。

---

## 0. 一句话

传播信道这个环节**不是一个模型，是一组可选的效应**。用户选一个档位（E1 快速抽象 / E2 工程 /
E3 精细机理），再逐项开关；每一档声明它包含哪些效应，输出随 `included_loss_terms` 走。

**缺省是 E1，等于本项目 2026-09-10 之前的行为**：自由空间路损 + 多普勒 + 时延，一个数不差。

## 1. 算在哪、为什么不算在信道组件里

计算落在**帧生产端**（`geo::link_budget()`，由 `ScenarioSource` 每 10–100 Hz 调用一次），
不落在 `SceneBoundChannel` 里。三条理由，任一条单独成立：

1. **分层**。EM-P-01/02/04/05/08/13 属 M1/M2 参数供给层，「M3 组件在采样率上施加」且
   「M3 不得绕过 M1/M2 自行硬编码传播参数」（CLAUDE.md「功能级—信号级衔接」）。
   `SceneBoundChannel` 是 M3 施加器，只做逐样点乘、相位斜坡、整数样点搬移。
2. **读数自洽**。场景页链路面板的「路损」取自 `link` 事件，事件由帧生产端产出。
   算在信道里，读数就与实际施加的不一致。
3. **复用**。测向误差预算（`geo/df_error.cpp`）吃的是帧里的信噪比，它依赖 `path_loss_dB`。
   算在生产端，测向自动跟着变。

**表达上一律经 `extra_loss_dB` 汇入**，替代型主模型也不例外（`extra = L_primary − L_fs`），
于是 `path_loss_dB = free_space_dB + extra_loss_dB` 在任何档位下都成立，参数帧结构一个字段不加。

## 2. 档位

| 档 | 名称 | 包含 | 状态 |
|---|---|---|---|
| **E1** | 快速抽象 | 自由空间路损 + 多普勒 + 时延 | ✅ **缺省** |

与地面双径、大气降雨可以同开。

## 3. 逐项模型

`d` 一律是 ECEF 弦长（D-049 ①）；`λ = c/f`，`c = 299792458`（D-009）。

### 3.1 自由空间（EM-P-01，E1 起，M2/E1/V2）

```
L_fs(d, f) = 20·log10(4π·d/λ)
```

解析锚点：2.4 GHz / 1 km = **100.0520080561155 dB**（`test_propagation.cpp` 守到 1e-12）。

### 3.2 地面双径（EM-P-02，E2，M2/E2/V1）

镜像法几何 + Fresnel 反射系数 + Rayleigh 粗糙度 + 部分相干叠加。`h_t` / `h_r` 是**离地高度**
（`alt_m − terrainHeight_m`，铁律 2 的显式平地假设，禁止把 DEM 海拔与离地高差隐式相加）。

```
d_d = d                                   直达路径
ρ   = sqrt(max(d_d² − (h_t − h_r)², 0))   水平距离
d_r = sqrt(ρ² + (h_t + h_r)²)             镜像反射路径
Δd  = d_r − d_d
cosθ_i = sinα = (h_t + h_r)/d_r           掠射角 α，入射角自法向起算

ε_c = ε_r − j·σ/(ω·ε_0),  ε_0 = 8.8541878128e-12 F/m
Γ_H = (cosθ_i − √(ε_c − sin²θ_i)) / (cosθ_i + √(ε_c − sin²θ_i))
Γ_V = (ε_c·cosθ_i − √(ε_c − sin²θ_i)) / (ε_c·cosθ_i + √(ε_c − sin²θ_i))
A_rough = exp[−(4π·σ_h·cosθ_i/λ)²]
Γ_eff = Γ_pol · A_rough                    A_div = A_shadow = A_material = 1（E2 档，§10.4 允许）

r  = |Γ_eff|·d_d/d_r
Δφ = arg(Γ_eff) − 2π·Δd/λ
C_2ray = 10·log10[1 + r² + 2·ρ_c·r·cos(Δφ)]        > 0 为增强
L_2ray = L_fs(d_d) − C_2ray                        限幅：C_2ray ≥ −max_fade_depth_dB
d_bp   = 4·h_t·h_r/λ                               断点距离，解释字段
```

**材质表**逐行取自本项目自有的《天津机场_地表材质与建筑数据工作流》§3.5：

| `ground_type` | ε_r | σ (S/m) | σ_h (m) |
|---|---:|---:|---:|
| `paved` | 5.0 | 0.008 | 0.003 |
| `grass` | 15.0 | 0.020 | 0.010 |
| `water` | 80.0 | 5.0 | 0.002 |
| `dirt` | 8.0 | 0.010 | 0.010 |
| `unknown`（缺省） | 8.0 | 0.010 | 0.005 |

**极化**取场景 `emission.polarization`：`vertical` → `Γ_V`，`horizontal` → `Γ_H`；
其余（`rhcp` / `lhcp` / `slant45`）按 EM-P-02 §10.4「极化未知时不得默认高可信相干深衰落」
取两者中幅度较小者并置 `degraded`。

**解析锚点与实测**（`engine/tests/test_propagation.cpp`）：

| # | 配置 | 结果 |
|---|---|---|
| A1 | 水面光滑、**水平极化**、`h_t = h_r = 5 m`、扫 `d ∈ [300, 2000] m` | `C_2ray ∈ [−20（限幅）, +6.01] dB`；相长在 `d ≈ 814 m`（`Δd = λ/2`），相消在 `d ≈ 407 m`（`Δd = λ`） |
| A2 | 接收端贴地（`h_r → 0⁺`） | `Δd = 0`，`C_2ray → 20·log10\|1 + Γ_eff\|` |
| A3 | `σ_h = 100 m`（远大于波长） | `A_rough → 0`、`C_2ray = 0`、**双径退化为自由空间** |
| A4 | `h_t = h_r = 2 m`（`d_bp = 130 m`），限幅放宽到 60 dB，20 km → 200 km | 路损增 **39.99 dB**，即 `d⁻⁴` |
| A5 | `demo-01` 的 `h_t = 50 / h_r = 30`，2.4405 GHz | `d_bp = 48.84 km`，**20 km 的观测区域内恒在干涉区**，看到的是起伏不是 `d⁻⁴` |

**三处要写明的限度**：

1. **垂直极化有伪 Brewster 凹陷**。0.7° 掠射的水面上 `|Γ_H| = 0.997` 而 `|Γ_V| = 0.80`，
   于是垂直极化的相长上界只到 `+5.1 dB` 而不是 `+6.02 dB`。这是物理，不是缺陷；
   A1 锚点因此必须用水平极化（最初按 `vertical` 写的那条断言就是这么红的）。
2. **限幅比零点浅时看不到远场渐近**。缺省 20 dB 限幅下，A4 的两端都被限住，
   斜率恰好退回 20 dB/十倍程（= 自由空间）。要看 `d⁻⁴` 必须把 `max_fade_depth_dB` 放宽。
   限幅本身是 EM-P-02 §10.8 第 3 条要求的（数值上完全相消会给出不现实的无限损耗）。
3. **`ρ_c` 缺省取 1.0（完全相干），是有意的演示取向**。EM-P-02 §10.6 的建议默认是
   `partially_coherent` 或 `noncoherent`（「不得默认输出高可信深衰落」）。取 1.0 是为了让「双径」
   这件事在演示里看得见；`ρ_c < 1` 时衰落状态一律降为 `averaged`，深衰落不作强裁决输出。

### 3.3 城市经验（EM-P-05 的 E1 档 log-distance，E2 档位内，M2/E1/V1）

```
L_emp = L_fs(d_0, f) + 10·n·log10(d/d_0) + X_env  [+ 1.2816·σ_sh  当 urban_loss_mode = mean_with_shadow_margin]
```

| `env_class` | n | X_env (dB) |
|---|---:|---:|
| `open` | 2.0 | 0.0 |
| `suburban` | 2.6 | 3.0 |
| `urban`（缺省） | 3.0 | 6.0 |
| `dense_urban` | 3.5 | 9.0 |

**参数来源标 `assumed`（原型阶段验证值，D-028）**。三件事必须一并写（照 D-019 的体例）：

1. **本项目自有实测只支持粗档结论「2.4 GHz 城市户外链路 `n ≈ 2`」**（D-019，`T0010` 六片 n = 1.93、
   `T0011` 三片 1.69）；
2. **那个 1.93 的前提是「距离取区间中点」这一计算假设**，真实距离比只能定在 2.0–7.5，
   同一实测降幅对应 `n = 1.29–3.75`；
3. **D-019 的样本是空地准视距链路**（无人机在空中），落在 `open`–`suburban` 之间。
   表里 `urban` / `dense_urban` 两行是地面站到街谷内目标的工程取值，**无本项目实测支撑，
   不得用于标定，也不得说成被 D-019 证实**。

**近区**：`d ≤ d_0`（缺省 100 m）时 log-distance 外推没有意义，退回 `L_fs(d)` 并置
`degraded = true`、`reason = "距离小于参考距离 d0，近区退回自由空间"`，`included_loss_terms`
相应不含 `urban_mean`。`demo-01` 的航线会飞到距站 33 m，因此 300 帧里有 105 帧走这一支——
这是设计行为，不是缺陷。

**解析锚点**：

| # | 配置 | 结果 |
|---|---|---|
| B1 | `env_class = open`（n = 2、X = 0），任意 `d > d_0`、任意 `f` | `L_emp` 与 `L_fs(d, f)` **逐值相等**（差 ≤ 1e-9 dB）——替代关系的钉子 |
| B2 | `d → d_0⁺` | `L_emp − L_fs(d_0) = X_env` 精确 |
| B3 | 十倍程 | `ΔL_emp = 10·n` dB |
| B4 | `mean_with_shadow_margin`、`urban` | 比 `mean` 档高 `1.2816 × 5.0 = 6.408 dB` |

### 3.4 统计阴影（EM-P-08，E2，M2/E2/V1）

dB 域零均值正态，沿航迹按**空间位移**一阶相关：

```
σ_sh = shadow_sigma_dB（≥ 0 时用它）否则按下表
ρ_k  = exp(−Δs_k / d_corr)      Δs_k = 第 k 帧与第 k−1 帧目标位置的 ECEF 弦长
X_0  = σ_sh·Z_0
X_k  = ρ_k·X_{k−1} + sqrt(1 − ρ_k²)·σ_sh·Z_k
```

| `env_class` | σ_LOS (dB) | σ_NLOS (dB) |
|---|---:|---:|
| `open` | 3.0 | 5.0 |
| `suburban` | 4.0 | 6.0 |
| `urban` | 5.0 | 8.0 |
| `dense_urban` | 6.0 | 10.0 |

`d_corr` 缺省 50 m。**σ 表与 `n` / `X_env` 同样是 `assumed`**。

**本期取不到 NLOS 一列**：`line_of_sight` 在显式平地假设下恒为真（`geo/src/link_budget.cpp:32`），
D3 接上几何视距判定后这一列与 `df_error.cpp` 的 `sigma_mp_nlos_deg`（缺省 5.0°）同时开始生效。
**选了「城市」环境不等于做了遮挡判定**——本模型只是把城市环境的统计效应加上去，
每一帧仍然报视距。

**复现性**：序列在 `ScenarioSource::init()` 里**按帧序一次算完存成向量**，`frame(k)` 只查表。
这是硬约束不是优化：`LinkFrameSource::frame()` 的类注释把「无副作用、可任意乱序、任意次数调用、
结果逐位相同」定为不变量，而 `process()` 对同一个 `k` 确实会调两次（一次出帧给端口、一次上报给观察者）。
每条 (站, 源) 链路一条独立子流，按 `links_` 的固定顺序自共享流派生；**不开阴影时一个数都不取**
（无条件抽取会把下游所有组件的子种子整体挪位——R-1 的产品字节比对就是这么红的）。

**统计锚点**（`test_propagation.cpp`）：

| # | 判据 | 实测 |
|---|---|---|
| C1 | 固定种子逐位复现、乱序取值结果相同 | ✅ |
| C2/C3 | `Δs ≫ d_corr` 时退化为独立抽样，40000 帧经验 σ | **6.0015**（设定 6.0，差 0.03%）；均值 −0.0196 |
| C4 | `Δs = 20 m`、`d_corr = 50 m` 的相邻帧相关 | **0.6687**（理论 `exp(−0.4) = 0.6703`，差 0.24%） |
| C5 | 递推稳态方差恒为 σ²，前后两半不漂移 | ✅ |

### 3.5 大气与降雨（EM-P-07，E2，M2/E1/V2，移植 emcore）

逐字移植 `C-UAV Model Demo/emcore/src/models/propagation.cpp` 的 `atmosphericLoss_dB` 与
`rainAttenuation_dB`，**保留原分段与原常数**（D-009：移植模块守原常数，禁止顺手统一）：

```
γ(f_GHz) = 0.005 + 0.001·f_GHz        f < 10 GHz
         = 0.01·f_GHz − 0.05          10 ≤ f < 50
         = 0.5 + 0.02·(f_GHz − 50)    f ≥ 50
L_atm  = γ · d_km
L_rain = 1e-4·f_GHz^1.5 · R^(1+0.02·f_GHz) · d_km      R ≤ 0 时为 0
```

黄金基准 `tests/golden/propagation.json`（自 emcore 拷入）：`atmosphericLoss_dB` 40 例 +
`rainAttenuation_dB` 24 例 = **64 例，rel ≤ 1e-9**。

**这两式不含光速常数**，因此 D-009 警告的「emcore 用 `3e8`、`geo/` 用精确值」在本模块**不构成冲突**；
冲突要到 D3 移植 `fresnelV` 与刀口衍射时才出现。

**适用范围**：在本项目的频段与距离上天气项很小——2.4405 GHz / 20 km 时大气 **0.1488 dB**、
25 mm/h 中雨 **0.2231 dB**，合起来不到 0.4 dB。留它是为了框架完整与将来的高频段，
不是因为它在 2.4 GHz 演示里重要。上游是 em-demo 的简化 ITU-R P.676 / P.838，
不是 ITU 建议书原文的完整实现。

### 3.6 建筑刀口绕射（EM-P-04，E3，M2/E3/V2，移植 emcore）

**这是 E3 这一档的定义性效应**。几何在 `geo/src/local_scene_adapter.cpp`（100 m 桶网格 +
线段遍历），物理在 `geo/src/occlusion.cpp`（ITU-R P.526 单刀口），接线在
`geo/src/link_budget.cpp` 的 `link_geometry()`（D3-5）。

**式子**（在 `legacy::` 里，守 148 例黄金基准）：

```
v = h·sqrt( 2(d1+d2) / (lambda·d1·d2) )                        菲涅尔-基尔霍夫衍射参数
L_ke(v) = 0                                        , v <= -0.78
        = 6.9 + 20·log10( sqrt((v-0.1)^2+1) + v - 0.1 ), v > -0.78
```

`h` 是视线**侵入**刀口顶的竖直深度，`d1 / d2` 是两端到刀口的地面距离（各自钳到不小于 1 米）。

**四条口径**：

| 口径 | 取值 | 为什么 |
|---|---|---|
| `line_of_sight` | `= !blocked`，**与损耗大小无关** | 这个布尔量的含义是「楼挡没挡住」，不是「损耗够不够大」。掠射只损 6 dB 也算非视距。界面据它给链路线上色，颜色要摆事实、不摆实施方挑的门限（D-039） |
| 损耗进哪 | 只进 `extra_loss_dB` | 于是 `path_loss_dB = free_space_dB + extra_loss_dB` 的恒等式在任何档位下都成立，`SceneParamFrame` 一个字段不加 |
| 倍数 | **单程乘一，不乘二** | emcore 的原注写的是「雷达双程乘二、单向链路乘一」。本系统是电子侦察单向链路。这是从雷达代码移植过来时最容易顺手抄错的地方 |
| 光速 | `3e8`（不是 299792458） | 刀口衍射这一整套是被 148 例黄金基准**整体**钉住的模块，只换其中一个常数会让它内部自相矛盾。量级是 **3e-3 dB**（07 §14.3 修正过这个数），物理上无关紧要、1e-9 的基准上是硬伤（D-009） |

**频率逐帧取**：菲涅尔参数与波长有关（`v` 正比于 `1/sqrt(lambda)`），而跳频源每次停留都在变，
所以用的是那一帧的 `center_Hz`（瞬时频点，不是跳频序列，D-069）。

**平面工作帧**：建筑与两个端点都经 `geo::SceneFrame` 投到平面米——原点取观测区域清单的
`aoi.center`，东 / 北取严格站心地平（铁律 1），**高度用离地高差、不用站心坐标的天向分量**
（10 km 外它已被地球曲率压低 7.8 m，铁律 2）。建筑与端点用的**必须是同一个帧对象**，
否则整份建筑集相对视线平移，而且不会报警。

**声明过的八条简化**（07 报告 §8，自 emcore / em-demo 的原始注释照抄不改，逐条标偏向）：

| # | 简化 | 偏向 |
|---|---|---|
| 1 | 高度按离地、地面视为平面（`terrain_height_m` 返回常数） | 与铁律 2 的显式平地假设一致；起伏地形下不定 |
| 2 | 侵入量用**竖直距**近似视线的垂线距 | 低俯仰角下成立；过顶时高估侵入，**偏保守** |
| 3 | 多栋楼只取**侵入最深的一栋**的单刀口 | 一条 3 km 的城市路径可能穿过几十栋楼，多刀口（Deygout / Bullington）会更大，**偏乐观** |
| 4 | `d1 / d2` 下限钳到 1 米 | 端点贴障碍时菲涅尔参数发散的工程钳位 |
| 5 | 建筑孔（内环）忽略 | **偏保守** |
| 6 | 端点落在楼的投影内即排除该楼（自遮挡） | 「架在楼顶」的合理处置；但「在楼里」会被当成楼顶 |
| 7 | 不做穿透、不做反射、不做材质 | 铁律 12；EM-T-04 留 P3 |
| 8 | 光速取 `3e8` | 3e-3 dB 量级，见上表 |

**第 3 条偏乐观、第 5 条偏保守，方向相反且量级未测**——所以这里只列清单，
**不给「整体偏保守」或「整体偏乐观」的合成结论**。

**建筑高度里近八成是按面积估算的**（`src=est:area`，78.55%，D-027b）。它们照常参与计算，
标记随数据层走、界面不解释（铁律 14、D-042b）。**这一档的绝对数值因此是原型阶段验证值**
（D-028），不得当作交付指标。

**解析锚点**：掠射 `v = 0` 时 `6.9 + 20·log10(sqrt(1.01) - 0.1) = 6.0329 dB`。

**实测**（demo-01，站点天线 30 米，原型阶段验证值；括号里是 07 §1.5 的调研值）：

| 位置 | 距离 | 刀口损耗 |
|---|---|---|
| 起飞点 | 211.1 m（调研 210） | **36.98 dB**（调研 37.0） |
| 过顶（t 7.2 至 26.4 s） | 33 至 269 m | **0，视距窗口** |
| 第一航段末 | 801.2 m（调研 799） | **28.39 dB**（调研 28.4） |
| 航线末端 | 3035 m | **32.30 dB**（调研 3155 m / 32.4） |

整条 180 秒航线 **89.3% 的帧判非视距**，刀口损耗均值 30.3 dB、最大 37.0 dB；
S3 上的带内信噪比在航线末端由 **33.7 dB（E1）降到 1.4 dB（E3）**，过顶那一段两档相同（35.8 dB）。
瀑布上因此呈「被挡、过顶拔起三十几分贝、远去重新沉下去」的三段式。

**站点天线高度是这一档最敏感的参数**（30 米抬到 60 米能把损耗均值砍掉一半，07 §1.5）。
它是**场景参数**（`sites[].position.alt_m`）不是模型参数——要让演示不那么暗，改场景、别改模型。

## 4. 防重复计损：一条规则 + 两道闸

EM-P-13 有八种 `model_role`、八种 `path_loss_semantics`、六种组合关系。本模块**不全套实现**，
压缩成一条规则：

> **至多一个「替代型主模型」；选中它就由它给出基础损耗，不再单独叠加自由空间。其余是加项。**

- **闸一（界面上就构造不出来）**：`prop_primary` 是单选（`free_space` / `two_ray` / `urban_empirical`），
  不是两个勾选框。
- **闸二（运行时裁决）**：城市经验取 `mean_with_shadow_margin` 时自带 90% 分位裕度，
  此时再开 `prop_shadow` 就是同源双计（EM-P-13 §10.9「若 EM-P-05 已抽样则禁用 EM-P-08」），
  `PropagationConfig::validate()` **报错并说明**，不静默禁用（铁律 15）。
- **闸三（D3-5）**：`E3` 加 `prop_shadow`。统计阴影建模的就是「建筑与地物遮挡造成的、随位置
  慢变的电平起伏」（EM-P-08），而 E3 已经按几何把同一件事确定性地算出来了。报错。
- **闸四（D3-5）**：`E3` 加 `urban_empirical`。城市经验的路损指数与环境偏置本身就是建筑密度的
  经验拟合（EM-P-05），同上。报错。于是 **E3 下 `prop_primary` 只能是 `free_space` 或 `two_ray`**；
  E3 加地面双径、E3 加大气降雨都允许（不是同一效应）。

**每条链路报告附 `included_loss_terms`**，取值域固定六项、顺序固定：

```
free_space | ground_reflection | urban_mean | diffraction | shadow | weather
```

`diffraction` 在 E3 档**每一帧都声明，包括视距帧**：下游问的是「这条路损里算没算过建筑遮挡」，
答案与这一帧恰好挡没挡住无关（EM-P-13 §10.9）。

`free_space` 恒在（替代型主模型的表达式里也含它）。下游据此判断能不能再叠加。
它进 `link` 事件与 `links.jsonl`，不进 `SceneParamFrame`（帧是 IQ 施加路径，加字段没有消费者）。

## 5. 降级语义（铁律 15、05 §6.2.3 四态）

传播模型自身的降级与 `valid` 正交：降级仍给得出可用的数，只是可信度降一档。
触发时 `LinkBudget.degraded = true` 且 `reason` 写明原因，帧的 `state` 变 `Degraded`，
经 `channel.cpp` 的 `worst()` 汇总进 IQ 块元数据，于是在结果四态上看得见。

| 触发 | 处置 | `included_loss_terms` |
|---|---|---|
| 双径：`h_t ≤ 0` 或 `h_r ≤ 0` | 退回自由空间 | 不含 `ground_reflection` |
| 双径：非线极化 | 取 `Γ_H` / `Γ_V` 中幅度较小者 | 照常含 `ground_reflection` |
| 城市经验：`d ≤ d_0` | 近区退回自由空间 | 不含 `urban_mean` |
| 城市经验：`d_0 ≤ 0` | 退回自由空间 | 不含 `urban_mean` |

**E1 缺省档下 `degraded` 恒假**，与 2026-09-10 之前逐字相同。

## 7. 已知取舍与适用范围

1. **环境类别放在信道参数里**（用户 2026-09-10 拍板第 ③ 条）。物理上环境是地理属性，
   这意味着同一个场景换一份框图就能变成另一种环境。要收紧就把 `env_class` 挪进场景的
   `sites[]` 或 `aoi`，框图只留「算不算它」——与 D-054 把天线增益与噪声系数挪进场景是同一个套路。
2. **`env_class` 与 `ground_type` 全图一份**（`ch` 槽位的 `owner` 是 `shared`）。三个站分处
   闹市与郊野时只能取一个类别；在 20 × 20 km 的演示 AOI 内可接受。
3. **`FreeSpaceChannel`（自由空间定参）不进传播效应体系**。它不吃场景参数帧，拿不到几何与航迹，
   高档位算出来的附加损耗不会被施加到 IQ 上，只会让链路读数名不副实。
   **2026-09-10（D-059）把该变体从框图页撤掉**——那个页面上能跑的配置一定有场景，
   手填一个固定距离永远是错的选择。组件本身保留：它是标准算例与解析锚点的对拍件
   （`test_channel.cpp` / `test_receiver_chain.cpp`），在自由画布与手写框图里照常可用。
   **残留风险**：画布里仍可搭出 `ScenarioSource(prop_level = E2)` + `FreeSpaceChannel`，
   此时链路读数与实际施加的 IQ 不一致。画布不跑频率计划检查，引擎也看不见别的节点的类型
   （`check_wiring()` 只拿得到自己被连上的输入口名，而 `ScenarioSource` 没有输入口）。
   属高级用法自负其责。
4. **除自由空间与天气两式外，全部参数标 `assumed`**，量化结论一律「原型阶段验证值」（D-028），
   甲方数据到货后按同一套锚点重估。
