# geo 目录

显示子线的物理侧：地图查询接口、场景适配器、刀口衍射遮挡。对应里程碑 D3。

## 来源

从 `C-UAV Model Demo/emcore/` 移植三部分（决策 D-005）：

1. `IMapQuery` 接口：地形高度查询、建筑查询、射线求交、材质查询
2. `LocalSceneAdapter`：100 米桶网格加数字微分分析线段遍历，命中语义是「侵入最深的等效单刀口」
3. `models/occlusion`：ITU-R P.526 刀口衍射

移植进来的文件必须在文件头注明来源，以及与哪一组黄金基准对应。

## 验收（两项缺一不可）

1. 148 例黄金基准对拍，相对误差不超过 1e-9
2. 独立的解析锚点，例如 2.4 吉赫兹、1 千米处的自由空间路径损耗约等于 100.1 分贝

只有解析锚点或只有统计校验都不够。既有项目里定位圆概率误差的公式错误，就是靠蒙特卡洛
散布校验才发现的，而它当时通过了解析检查。

## 常数策略（决策 D-009，容易踩）

从 emcore 移植过来的模块**保留原常数**，以守住黄金基准：光速用 `3e8`；遮挡投影用
`110540` 与 `111320·cosφ`；定位投影用双向 `111320`；到达时间差用 `299792458`。

新写的代码统一用 `c = 299792458` 与严格的站心坐标系。

**禁止"顺手统一"常数**，那会破坏黄金基准。
