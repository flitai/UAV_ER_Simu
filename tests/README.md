# 测试目录

五级验证，对应 04 号方案 §15.1。验收入口是 `tests/golden` 与 `tests/regression` 全部通过，
外加 04 §15.2 的十二项标准算例。

| 目录 | 级别 | 验什么 | 现状 |
|---|---|---|---|
| `unit/` | 单元测试 | 单个函数或类的行为。合成输入，快速运行 | 空 |
| `integration/` | 集成测试 | 多个组件串联后的行为，例如波形生成接信道再接采样链 | 空 |
| `e2e/` | 端到端测试 | 从浏览器操作到引擎运行再到结果回显的完整链路 | 空 |
| `golden/` | 黄金基准 | 与冻结的参考输出逐位或按容差对拍。**相对误差不得超过 1e-9** | 空 |
| `regression/` | 回归算例 | 标准算例与跨层一致性算例，清单见该目录的 README | 清单已列，实现待做 |

## 两条纪律

1. **基准不得静默变**（铁律 10）。任何模型、参数或数据集的变化，都不得静默改变既有的
   基准结果。超出容差就是一个发现，必须查根本原因，**禁止调参使其通过**。
2. **随机性显式注入**（铁律 9）。随机源通过接口或请求参数传入，库内不得有全局随机源。
   固定种子必须逐位复现。随机量用蒙特卡洛矩校验。
