## 二、四项跨层一致性算例（01 §8.3）

这四项检查同一场景、同一随机种子、同一参数版本下，从 IQ 级归约到信号级或功能级的统计量，
与功能级、信号级直接计算值之间的相对偏差。偏差超出容差就是一个发现，必须追查是抽象误差、
参数不一致、样本不足还是适用范围问题，**禁止挑选有利的结果**。

| # | 算例 | 比对双方 | 状态 |
|---|---|---|---|
| ① | 自由空间加高斯白噪声，单音与突发 | EM-S-02 的检测概率公式 与 IQ 级蒙特卡洛检测概率 | [ ] |
| ② | 建筑遮挡 | EM-P-04 的附加损耗 与 IQ 级接收功率统计 | [ ] |
| ③ | 双径 | EM-P-02 与 IQ 级复信道功率起伏 | [ ] |
| ④ | 混合增强 | 实测背景加合成目标的信噪比归约 与 信号级预测 | [ ] |

**容差尚未冻结**。参考值见 04 §16.3：检出率允许相差 5 至 10 个百分点，功率统计允许相差
10% 至 20%。按指标分别冻结，决策时点是阶段 1 设计报告。

**算例 ① 已列入 P1 的退出条件**，但该条属暂定状态（决策 D-014），因为 04 §13.3 原文没有
这一条，需在 04 修订时确认。

## 三、可以用公开数据集 DroneRFb-DIR 支撑的算例

摸底结论见 `WORKLOG.md` 的 2026-09-03 条目。该数据集接在仿真链条的 S4 观测点之后，
因此只能支撑链条下游的算例。

| 算例 | 能否用该数据集 | 说明 |
|---|---|---|
| 标准算例 9 实测 IQ 回放 | 能 | 转换格式后可直接作为回放源 |
| 标准算例 10 实测背景加合成目标 | 能 | 62 个纯背景片段可用作真实城市背景 |
| 跨层一致性 ① | 能（升级版） | 把高斯白噪声换成真实背景，产出更可信的检测概率曲线 |
| 跨层一致性 ④ | 能 | 与标准算例 10 同源 |
| 跨层一致性 ② | 只能做量级检查 | 无坐标、无绝对功率标定，不能校准。论文给的「视距与非视距信噪比相差约 20 分贝」可用作量级合理性检查 |
| 跨层一致性 ③ | 不能 | 无高度、无距离变化，双径特征无从体现 |
| 标准算例 1 至 8、11、12 | 不适用 | 这些验的是链条上游，必须用参数已知的合成数据 |
